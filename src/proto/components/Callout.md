# Proto Callout

`Callout` is a presentation-only, portaled speech bubble. It uses the existing watercolor emoji atlases; it does not import the legacy Golf game or its styles. Text stays in sentence case and wraps. Motion respects the operating system preference.

Opt into `syncActorExpression` to publish Hero's resolved emoji emotion to the shared actor expression store, including saved callout overrides. The callout owns a lease that clears on closing or unmounting. Actor renderers choose only face layers authored for their current pose/view; Day 01 currently supports seated sadness.

Pass `anchor: { x, y }` in viewport CSS pixels for static placement, or a stable callback for live actor/camera tracking. Return null when the actor is unavailable or concealed. Placement writes to the DOM without React frame updates. Resize observation handles text and viewport changes. Live placement searches viewport-safe space clear of all map/interior/combat actor bounds, including the speaker, with tail/motion clearance. Supply `avoidActors()` for another scene's projected viewport rectangles. Side placements omit the misleading vertical tail. If no free rectangle can contain the bubble it stays hidden and its reveal pauses until space becomes available; it never covers an actor.

Use `useCallouts()` for a bounded active list (default three). `show(message)` replaces an existing message for the same speaker; `dismiss(id)` and `clear()` remove messages. Render each entry as `<Callout key={id} instanceKey={id} {...message} onDismiss={() => dismiss(id)} />`. A positive `durationMs` requests dismissal through `onDismiss` after a single bubble finishes revealing (default 5000 ms); zero persists. Multi-bubble dialogue always waits for player advancement. Changing `instanceKey` restarts its lifetime. Timers and observers clean up on unmount. Callers own story triggers and discovery gates.

Blank lines author separate bubbles; paragraphs longer than 110 characters paginate at sentence/word boundaries, preserving effect offsets. `letterMs` defaults to 32 milliseconds per letter (0 is instant), with 1.55× delay for marked text and short punctuation pauses. The editor saves this speed and explicit breaks locally. Whole words retain their final footprint while letters appear, without a blinking cursor or text reflow. `paused` and hidden/unavailable scenes freeze reveal; reduced motion and edit mode reveal instantly. Accessible text announces each complete page once. Click/tap or Enter first reveals remaining letters, then advances to the next page; the last activation hides the callout and invokes `onComplete` and `onDismiss`. Use `onComplete` for owner-controlled story continuation, as in Banks rescue. Editing disables advancement. The surface accepts pointer input; the surrounding scene remains interactive. Space toggles global pause; O toggles OTT/immersion.

Emoji selection is a typed `{ actor, emotion }` pair for Hero, Mochi or Banks. `expression` accepts custom decorative artwork. Text is announced politely; artwork is decorative. Tones are dialogue, gold and warning.

Preview: `/tools/callout-preview.html`. This scaffold does not assign new dialogue to gameplay. Independent bubbles can overlap; the hook bounds chatter but does not implement scene-wide collision resolution. Keep messages brief enough to fit the available viewport height.

Wrap the game in `CalloutEditingProvider` with `enabled` bound to developer Edit mode. Active callouts expose a pencil to open a modal emoji/text editor with a live preview. Select text and apply Emphasis, Shake, Wave, Glow, Whisper or Rainbow, or Clear effect. Select an effected phrase to adjust its color and potency (0–200%) in the live preview. Tuning persists per phrase; existing marks default to 100%. Rainbow color sets the starting hue and potency controls saturation. Motion becomes static under reduced motion. Save persists overrides in localStorage; Cancel discards the draft and Restore original removes the override. Supply a stable `authoringId` for each authored beat, independent of text and transient instance lifetime. Without it, speaker and instanceKey (or original text) provide a fallback. Saved overrides apply during play even outside Edit mode and never serialize into tile documents.

Callout camera presets: the editor can capture/adjust one shot or bind a saved named choreography. Automatic playback runs once per callout instance in play mode, including offscreen anchors so a shot can bring the speaker into view. Caller visibility/discovery gates remain authoritative. `authoringId` also identifies callout triggers in Camera choreography. Sequences use the shared map-camera adapter in `cameraDirector.ts`; named triggers are dispatched through `fireCameraTrigger(event, value)`. See `docs/camera-choreography.md`.

Edit workspace: the modal owns pointer and wheel input. Use Text & effects, Expression, Camera and Preview tabs; camera shots have Framing, Shot and Timing components. Save/reset/cancel commands remain above the ribbon. Drag the title bar to reposition; placement clamps to the viewport. Drafts survive tab switches. Small screens retain local overflow.
