# Hero walking cycle

Built-in ImageGen, 2026-10-12. Low: five directions × four phases. High: five elevated directions plus overhead × four phases. `tools/prepare-hero-walking.cjs` measures opaque silhouette components and packs four equal phase rectangles per view with a shared foot baseline. It isolates each cutout's solid silhouette and nearby alpha fringe to remove faint bridges and neighbouring sprite fragments, retaining its original colors and genuine alpha. Original generation sheets remain unchanged. Runtime artwork shares the existing head/torso/hind rig. Low/elevated views mirror for opposite directions; overhead follows world heading. Walking advances by distance, reduced motion holds phase zero.
