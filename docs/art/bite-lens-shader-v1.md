# Bite lens shader trial

This is an experimental screen-space approximation of a lenticular sheet, scoped to Bite. A lenticular print interlaces source images beneath lenses so the visible image changes with viewing angle; [Kodak's technical overview](https://www.kodak.com/content/products-brochures/How-does-lenticular-printing-work-white-paper-EN.pdf) describes that mechanism. The implementation is independently authored GLSL, not a copied shader or a physical diffraction/optics solver. Refraction and pearl/color accents are deliberate artistic approximations.

The uniform-coating revision applies refraction and red/blue separation to the complete composited foreground/background plate. A separate 1.8× coating gain strengthens lens ridges, glints and displacement without changing the original jaw-exchange strength or thresholds. These effects retain a face-on minimum instead of fading away with lateral angle, so static fur and the forest have the same continuous lens coverage as the mouth. Text and borders remain crisp. The saved strength/pitch controls keep their existing values and range.

`src/proto/biteOpticsShader.ts` samples the existing closed, parted, half-open and open jaw paintings plus the existing forest background. Each fragment gets a cylindrical-lens phase from its horizontal position and the shared card spring's viewing angle. Near an angular frame transition, neighboring frames exchange through narrow vertical slivers rather than a uniform crossfade. Small per-lens view differences, bounded UV refraction, restrained red/blue separation and lens-facing highlights create disruption while preserving the face and pale watercolor masses. The frame thresholds and closed/open direction remain the same as the original angle flip. There is no time uniform and no autoplay loop.

Gear → Bite lens experiment exposes a remembered on/off comparison, strength (0–100%) and lens pitch (1.5–5 CSS pixels). Defaults are on, 55% and 2.4 pixels. Zero strength suppresses optical disruption and highlights, retaining a simple angle blend. Switching the shader off restores the original DOM frame presentation. Labels, rarity foil, HP, value, input hitboxes and gameplay remain outside the shader.

The canvas follows the existing pointer/gyro spring and redraws on changes, resize, visibility and intersection, with no idle render loop. GPU texture uploads are bounded to a 1024px long edge per image; canvas resolution caps DPR at 2 with additional 1200×1600 limits. Runtime resampling does not alter saved source artwork or its alpha. Textures, shaders, program and buffers are released on cleanup; GPU context loss restores the DOM view and context restoration reconstructs the renderer. Loading or unavailable WebGL keeps the DOM view. Reduced motion and low/off effects show the closed painting.

Validation: `tools/bite-optics-shader-check.cjs` exercises compilation/render readiness without GL errors, actual pointer-angle captures, simulated context loss/recovery, remembered comparison controls, reduced-motion reset and return, mobile layout, and a deliberately unavailable Bite WebGL context. `tools/bite-lenticular-check.cjs` and `tools/bite-reaction-gyro-check.cjs` cover angle reversal, static fallback, flinch replacement/restoration and injected device orientation. Screenshots: `output/bite-optics-{closed,transition,open}.png` and `output/bite-optics-phone.png`. Headless software rendering and injected sensor events do not measure physical-phone GPU performance or hardware sensor permission.
