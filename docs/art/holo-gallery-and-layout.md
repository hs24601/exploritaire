# Shared lenses, radial inspection and status clearance

All `TradingCard` surfaces with `finish="diagonal-holo"` now mount the shared lens treatment. The master code switch is `HOLOGRAPHIC_LENTICULAR_ENABLED` in `src/proto/holoOpticsSettings.ts`; the same module owns the remembered runtime toggle and shared strength/pitch. Existing Bite settings migrate into the new global key. The gear panel calls the control “Lenticular effect (all holocards).” Frozen presentation clones also obey a root flag, so toggling off reaches copied card faces.

Bite keeps its four-jaw-image WebGL renderer. Other holocards filter their existing composed DOM artwork through an independently authored SVG displacement map, plus a tilt-responsive fine lens-ridge/pearl coating. This preserves original layered art and avoids taking raster snapshots or opening a GPU context for every gallery card. The refraction map and overlay use the shared tilt variables. Text stays outside the filter; plain cards are excluded. Reduced motion and low/off effects suppress the coating. The static cards have optical surface effects, not invented alternate animation frames.

The foundation inspector is now a full-screen floating radial gallery. It starts with the Keru identity card centered precisely in the viewport. Ability paintings form an elliptical ring that adapts to portrait/landscape dimensions. Tapping an ability trades its slot with the center card. The incoming and outgoing cards follow opposite curved paths for 720 ms; after the exchange the former center card can be tapped to swap back. Keyboard activation follows the same path. Reduced motion performs an immediate exchange. Existing authored Fetch/Dig PNG masters are now correctly wired into runtime previews where the previous WebP references were missing.

Musical tableau layout reserves a compact band above the foundation row, including clearance for the prime value ornament. Foundation groups align at the top. Buff/debuff trays now occupy normal flow after each foundation's HP/AP reservation; their wrapped height contributes to the fitted board. This prevents End Turn from covering extra status rows. The viewport fit remains responsible for short screens.

Fast Swipes' far and middle afterimages were moved from above the head to the shoulder/chest band, with the far layer behind Mochi's main painting. Their independent depth motion remains intact.

`tools/holo-radial-layout-check.cjs` verifies a centered jumbo, reversible card exchanges and active crossing animations; all-card lens toggling; reduced-motion exchange; wrapped-status/footer separation; and tableau/value gaps at 1440×900, 390×844, 390×667 and 844×390. Observed gaps were 17, 17, 13.8 and 6.1 screen pixels respectively. `tools/bite-lenticular-check.cjs` and `tools/prime-transfer-check.cjs` verify preserved Bite tilt behavior and prime drag interactions. TypeScript passes. Earlier sidebar-gallery screenshots/tests describe the superseded inspector; the radial check is the current gallery validation.
