# Berry brushwork revision v2

The user requested less detailed berry bushes using GAME.md's broad wet brush dabs, large pigment pools and deliberately lost detail, for both OTT and immersion. Generated with the built-in ImageGen tool in edit mode; original v1 sources remain available.

## Runtime assets

- `public/assets/biomes/watercolor-v1/berry-patch-sprite-v2.png`: five low camera-facing bushes for immersion and inspection cards.
- `public/assets/biomes/watercolor-v1/berry-patch-overhead-v2.png`: matching vertical overhead print for OTT.

The shared scenery selector chooses these in Paint mode. Pixel artwork, ground, den and tree assets retain their existing selection. Original PNG alpha and full-resolution smooth sampling are preserved without filtering, downsampling or volume reconstruction.

## Exact front edit prompt

Use case: style-transfer. Edit target: the attached berry patch front sprite. Create its dramatically simpler brush-painted revision for a small immersive game prop. Preserve five distinct LOW rounded bushes, three behind two in front, overall width/height and green/jade/olive foliage with magenta/wine berry identity. Preserve actual transparent background and roomy gutters, separated crowns and visible ground gaps. Change the painting language completely: each bush is an unfinished gestural watercolor thumbnail made from about 6–10 LARGE irregular wet brush dabs and a few broad pigment pools. Lose almost all small detail. Foliage should read as sweeping merged washes, NOT many little leaves. Fruit is only 2–3 irregular pink/wine pooled paint accents per crown, suggesting berries without individual beads. Only a few sparse broken brown/indigo tapered strokes suggest short stems. Soft wet-on-wet transitions, water-diluted edge fades, controlled bleed, imperfect wash registration, selective hard pooled boundaries; strong deep jade and rich olive values retained. Smooth translucent bleed at fringes, opaque foliage interiors. Absolutely no individual leaves, leaf veins, berry spheres, glossy white highlights, serrated clumps, tiny repeated strokes, photographic rendering, dense branches, stippling, grain, gritty paper noise, digital microtexture, vector-clean shapes, pixelation, 3D relief. No ground, shadow, paper rectangle, text or watermark. This is a loose broad-brush watercolor sketch, not a detailed botanical illustration.
