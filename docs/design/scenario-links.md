# Scenario links, first pass

On musicaltableaus, Copy scenario link appears beside the scene controls and works even during enemy turns or global pause. The button copies a self-contained link. A selectable link disclosure provides manual copying when clipboard access is unavailable. No server or account is needed.

The readable `scenario` query selects the encounter. `battleSnapshot=1g.…` stores a gzip-compressed base64url JSON envelope with schema version 1 and scene identity. Its complete battle state contains party and enemy stats/statuses, foundations/piles, abilities and rarity, passive counters, turn/round/timers, Momentum, tableau columns, stock order, dealt count, stored seeds and encounter-specific state. Historical hit-notification events are omitted to avoid replaying effects after hydration; event sequence numbering is retained. Other existing query parameters are preserved.

Restore validates the envelope, required simulation fields, supported scenario, numeric values, basic actor/enemy/card shapes, duplicate party IDs and dangerous object keys. Encoded payloads are limited to 64,000 characters, decompressed JSON to 1 MB and nesting depth to 40. Invalid/unsupported links leave the normal initial scenario and show an error. Imports begin locally paused before asynchronous decoding, then use the global clock pause after hydration. Resume scenario explicitly releases that pause; the scene's Space shortcut continues to mean End Turn.

The copied checkpoint becomes the restart checkpoint for that encounter. The link is a point-in-time snapshot, not a live URL synced on every move. The first pass targets musical combat only. Music, camera, cosmetic foil preferences, available-card visibility, DOM animations and in-flight pointer gestures are not serialized. Stored seeded randomness is preserved; future external/unseeded random inputs are not a deterministic replay contract. Versioning allows future rejection/migration, but compatibility with arbitrary future rule changes is not guaranteed. Gzip support is required. Very large scenarios can exceed the link budget and report an error instead of copying a truncated state.

Validation: `scenarioSnapshot.test.ts` covers full compressed round trips, URL query preservation and malformed/oversized/unsupported snapshots. `tools/scenario-share-check.cjs` copies an edited two-member scenario 101, restores it in a fresh page, compares the complete normalized state, verifies pause stability and resume, and checks invalid-link fallback. The tested edited snapshot produced a 1,585-character link. Browser tests stub clipboard delivery; the manual-copy fallback remains available when native clipboard permission is denied.
