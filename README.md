# Portals world

A dependency-complete snapshot of Hero's Portals game: Yggdrasil, Combat Woods and Painted Valley, with Flurry, controller navigation, shared combat, artwork and world authoring.

Run `npm ci` and `npm run dev`, then open `http://localhost:5178/portals.html`. Use `?combat`, `?tree` or `?valley` to choose where to start.

See [PORTALS.md](PORTALS.md) for build/test commands, controls, captured components and the dependency manifest.
