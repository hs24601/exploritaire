# Constellation chamber palette

26 selected VSCO 2 Community Edition samples (CC0-1.0).

Credits: Versilian Studios / Sam Gossner; Ivy Audio / Simon Dalzell;
sample cutting Elan Hickler / Soundemote.
Source: https://github.com/sgossner/VSCO-2-CE

See LICENSE, original Readme.txt and manifest.json for the pinned source commits,
individual source paths, SHA-256 records, prepared sample roots and loop points.
The original WAVs/SFZ mappings are retained in the corresponding assets/sources
directory. Preparation uses tools/prepare-musical-orchestra.py; implementation,
arrangement and validation details are in docs/musical-orchestra.md.

This palette contains harp (the supplied KSHarp patch), recorded flute and viola
section, and glockenspiel. It is a curated Web Audio sample bank, not a full SF2
or SFZ player. Prepared files are mono PCM16 at their original sample rate.
