## Preparation

`node tools/prepare-dem-standing.mjs --combat` separates the eleven connected bear cutouts in each source, preserves their original alpha edges and repacks them into 2048x1536 runtime sheets with gutters. It writes `src/proto/art/demCombatLayout.json`. The generated sources used smaller canvases than requested; actual dimensions are measured during preparation, never assumed. Runtime frame order is five low views, five elevated views, one overhead view.

The renderer reuses Dem's registered head/torso/hind hierarchy, with fixed coherent contact and recoil artwork. `demCombatSprites.ts` supplies a 0.72-second wind-up/contact/recovery hit and a 0.5-second recoil/recovery flinch using a caller-owned clock, brief directional root movement and a flinch flash. All displacement and flash reset on completion. Reduced motion holds a static authored pose briefly, then restores standing.
